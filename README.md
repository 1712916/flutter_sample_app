# 🐱 Meow App

Meow App is a fun and interactive Flutter application designed for cat lovers! It allows users to browse high-quality cat images, get random cat facts, and even play adorable cat sounds. Built with Flutter, Meow App is fast, responsive, and available on both Android and iOS.

---

## 🎨 UI
I’ve designed Meow App to resemble *Locket*, a trending application known for its clean and minimalist user interface.

## 🚀 Features
✅ **Switch Images**: Seamlessly switch between cat and dog images.  
✅ **Browse Cat/Dog Images**: Explore a vast collection of high-quality, royalty-free images.  
✅ **Share**: Easily share your favorite cat images with friends and family.  
✅ **Game**: A simple and fun sorting game for entertainment.
✅ **Chat**: A place to keep personal notes, game history, and fun moments every day.
